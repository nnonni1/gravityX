# GravityX architecture

GravityX has two related but distinct evidence paths.

**Prototype path:** Physical assembly → ultrasonic/IMU/environmental sensing → Arduino/VEX controllers → motor, servo, alarm, and safety logic → experimental AI analysis → telemetry → mission-control interface.

**Model path:** Rotational inputs → artificial-gravity calculation → electromagnetic induction model → buffer-power model → hybrid power budget and 48-hour demand profile.

The first path documents proof-of-concept hardware, embedded experiments, and interface demonstrations. The second is numerical/design analysis, not power produced by the prototype. Dashboard values are representative browser data, not operational telemetry.
